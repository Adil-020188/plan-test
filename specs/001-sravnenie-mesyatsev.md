# Сравнение почасового потребления предыдущего и текущего месяцев

## Для кого и зачем

Для субъекта оптового рынка электроэнергии, чтобы сопоставить потребление за выбранную дату предыдущего месяца с потреблением за выбранную дату текущего месяца, увидеть почасовые отклонения и общие объёмы, а также зафиксировать тарифы обоих месяцев.

## Что должно быть

- В форме есть два поля даты: «Предыдущий месяц» и «Текущий месяц».
- Для каждой выбранной даты показаны 24 строки: `00:00–01:00`, `01:00–02:00` и далее до `23:00–00:00`.
- В каждой строке слева направо расположены:
  1. час;
  2. поле объёма предыдущего месяца, кВт*ч;
  3. поле объёма текущего месяца, кВт*ч;
  4. разница объёмов, кВт*ч;
  5. разница, %.
- Разница объёмов рассчитывается автоматически: `текущий месяц − предыдущий месяц`.
- Процент рассчитывается автоматически: `(текущий − предыдущий) / предыдущий × 100`.
- Если объём предыдущего месяца равен нулю или не введён, процент не рассчитывается; вместо числа показывается «—». Значения `NaN` и `Infinity` не показываются.
- Под 24 строками показаны общие объёмы предыдущего и текущего месяцев и их общая разница. Общий процент рассчитывается по тем же правилам на основании общих объёмов.
- Под итогами есть отдельные поля тарифов для предыдущего и текущего месяцев:
  - тариф без НДС, ₸;
  - тариф с НДС, ₸.
- Объёмы указываются в кВт*ч. Допускаются ноль и положительные числа, в том числе дробные. Пустое или неверное значение объёма не участвует в сумме.
- Тарифы сохраняются только как целые неотрицательные суммы. Пустой или неверный тариф не сохраняется, рядом показывается понятная подсказка.
- Денежные значения отображаются в целых тенге с пробелами между тысячами, например `15 000 ₸`.
- Выбранные даты, почасовые объёмы и тарифы сохраняются в `localStorage` и восстанавливаются после F5.
- Данные сохраняются раздельно для выбранных дат, чтобы смена даты не перезаписывала данные другой даты.

## Примеры

- Выбраны даты 15.10.2026 и 15.11.2026. За `00:00–01:00` введено `100` и `120` кВт*ч → разница `20` кВт*ч, разница `20%`.
- За `01:00–02:00` введено `100` и `80` кВт*ч → разница `−20` кВт*ч, разница `−20%`.
- За час введено `0` и `10` кВт*ч → разница `10` кВт*ч, процент `—`.
- В трёх заполненных часах предыдущего месяца введено `100`, `200`, `300` кВт*ч → общий объём `600` кВт*ч.
- В два часа одного месяца введено число `1` и по 308 нулей → значения считаются неверными, не сохраняются, общий объём остаётся `0`, `NaN` и `Infinity` не появляются.
- В тариф введено `15000` → после завершения ввода показано `15 000 ₸`.
- В тариф введено `abc` или поле оставлено пустым → значение не сохраняется, показывается подсказка, `NaN` не появляется.
- Сначала сохранён тариф `15000`, затем в это же поле введено `abc` → после F5 снова показан последний корректный тариф `15 000 ₸`.

## Ограничения

- Только HTML, CSS и JavaScript без библиотек, npm и внешних ресурсов.
- Данные не отправляются в интернет и хранятся только в браузере.
- Дата слева должна относиться к календарному месяцу перед месяцем правой даты. Если даты не соответствуют этому правилу, показывается подсказка и сравнение не сохраняется.
- Интерфейс полностью на русском языке.
- Поля и кнопки имеют размер не меньше 44px.
- На экране шириной 375px все данные доступны: таблица может прокручиваться по горизонтали, при этом подписи столбцов и часы остаются понятными.
- Расчёт итогов, разницы и процентов выполняется без перезагрузки страницы после каждого изменения объёма.
- Не добавлять расчёт стоимости электроэнергии: в этой функции нужны только объёмы, разница, проценты и ввод тарифов.

## Готово, когда

- Можно выбрать корректные даты предыдущего и текущего месяцев и увидеть для них 24 часовых интервала.
- Для каждого часа можно ввести объёмы обоих месяцев и сразу увидеть верные разницу и процент.
- Под формой показаны верные общие объёмы, общая разница и общий процент.
- Можно отдельно ввести тарифы без НДС и с НДС для каждого месяца; неверные суммы не сохраняются.
- Денежные значения показываются в формате `15 000 ₸`, а `NaN` и `Infinity` нигде не появляются.
- После F5 выбранные даты, объёмы и тарифы остаются на месте.
- При смене дат ранее сохранённые данные можно снова открыть без потери.
- Страница пригодна для работы на телефоне шириной 375px, а все интерактивные элементы не меньше 44px.
