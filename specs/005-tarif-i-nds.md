# Тариф и НДС

## Для кого и зачем

Для субъекта оптового рынка электроэнергии, чтобы в разделе «Аналитика» задать тариф без НДС и ставку НДС отдельно для предыдущего и текущего месяцев, а затем автоматически получить стоимость потреблённой электроэнергии. Пользователь вводит только исходные значения, а суммы без НДС, НДС и с НДС рассчитываются по месячным объёмам без ручного ввода.

## Что должно быть

- Блок тарифов переносится с главной страницы в раздел «Аналитика» и располагается справа от месячной формы на широком экране.
- Для выбранного в аналитике месяца одновременно показаны два блока: «Предыдущий месяц» и «Текущий месяц». В каждом блоке явно указаны соответствующие месяц и год.
- Для каждого месяца есть только два поля исходных значений:
  1. «Тариф без НДС, ₸/кВт*ч»;
  2. «НДС, %».
- Поле ручного ввода «Тариф с НДС» удаляется. Тариф с НДС вручную не вводится.
- Тариф без НДС может быть нулём или положительным дробным числом. Разрешён ввод дробной части через запятую или точку.
- НДС может быть нулём или положительным дробным числом. Для месяца, у которого НДС ещё не сохранён, поле получает начальное значение `16`.
- Пустой, отрицательный, неверный или чрезмерно длинный тариф не сохраняется. Рядом с полем показывается короткая понятная подсказка.
- Пустой, отрицательный, неверный или чрезмерно длинный НДС не сохраняется. Рядом с полем показывается короткая понятная подсказка.
- Для предыдущего и текущего месяцев автоматически показываются:
  - месячный объём, кВт*ч;
  - сумма без НДС;
  - сумма НДС;
  - сумма с НДС.
- Сумма без НДС рассчитывается как `месячный объём × тариф без НДС`.
- Сумма НДС рассчитывается как `сумма без НДС × НДС / 100`.
- Сумма с НДС рассчитывается как `сумма без НДС + сумма НДС`.
- Сумма без НДС, сумма НДС и сумма с НДС округляются до двух знаков после запятой. Они показываются с запятой как разделителем дробной части, пробелами между тысячами и словом «тенге», например `2 334 645,45 тенге`. Даже при отсутствии дробной части всегда показываются два знака: `155 000,00 тенге`. В расчётах до вывода используются неокруглённые значения, чтобы сумма с НДС не накапливала ошибку округления.
- Результаты пересчитываются сразу после изменения тарифа, НДС или любого почасового объёма соответствующего месяца без перезагрузки страницы.
- Тариф без НДС и НДС сохраняются в `localStorage` отдельно для каждого календарного месяца, а не для отдельной даты. Выбор другого месяца показывает его собственные значения.
- Ранее сохранённый тариф без НДС для любой даты месяца переносится в данные этого календарного месяца без потери. Ранее сохранённое значение ручного тарифа с НДС больше не показывается и не используется в расчётах.
- После F5 выбранный месяц, тарифы и ставки НДС восстанавливаются, а суммы рассчитываются заново по сохранённым объёмам.

## Примеры

- Выбран ноябрь 2026 года → справа показаны блоки «Октябрь 2026» и «Ноябрь 2026» с отдельными полями тарифа и НДС.
- Для ноября ещё нет сохранённого НДС → в поле «НДС, %» показано `16`. Пользователь меняет значение на `12`, выбирает другой месяц и затем возвращается к ноябрю → снова показано `12`.
- Объём ноября равен `10 000` кВт*ч, тариф без НДС — `15,5` ₸/кВт*ч, НДС — `16%` → сумма без НДС равна `155 000,00 тенге`, сумма НДС равна `24 800,00 тенге`, сумма с НДС равна `179 800,00 тенге`.
- Объём октября равен `1 001` кВт*ч, тариф без НДС — `10,25` ₸/кВт*ч, НДС — `16%` → сумма без НДС показана как `10 260,25 тенге`, сумма НДС — `1 641,64 тенге`, сумма с НДС — `11 901,89 тенге`.
- Пользователь вводит тариф `12.75` → значение принимается как дробный тариф `12,75` ₸/кВт*ч и участвует в расчёте.
- Пользователь вводит в тариф `-5`, `abc` или оставляет поле пустым → новое значение не сохраняется, показывается подсказка, а после F5 восстанавливается последнее корректное значение.
- Пользователь вводит в НДС `-1`, `abc` или оставляет поле пустым → новое значение не сохраняется, показывается подсказка, а в расчётах не появляются `NaN` или `Infinity`.
- Тариф и НДС сохранены для ноября 2026 года, затем выбран декабрь 2026 года → для декабря показаны отдельные значения, а ноябрьские данные не перезаписываются.
- В ноябре изменён один почасовой объём → месячный объём и все три денежные суммы ноября сразу пересчитаны.

## Ограничения

- Только HTML, CSS и JavaScript без npm, библиотек и внешних ресурсов.
- Данные не отправляются в интернет и хранятся только в `localStorage` браузера.
- Объёмы указываются в кВт*ч, тарифы — в тенге без учёта НДС, ставка НДС — в процентах.
- Тариф и НДС хранятся по календарному месяцу в формате `ГГГГ-ММ`. Дни одного месяца используют одни и те же значения.
- Ноль является допустимым значением для тарифа и НДС.
- Значения `NaN` и `Infinity` не сохраняются и не показываются.
- Если тариф или НДС ещё не заданы корректно, вместо денежных результатов показывается «—». При нулевом месячном объёме и корректных тарифе и НДС показывается `0,00 тенге`.
- Интерфейс полностью на русском языке. Все поля и нажимаемые элементы имеют размер не меньше 44px.
- На экране шириной 375px блок тарифов располагается под месячной формой, не вызывает горизонтальную прокрутку всей страницы и остаётся полностью доступным.
- Эта функция не меняет правила ввода почасовых объёмов, сравнения месяцев, импорта `.xlsx` и расчёта отклонений.

## Готово, когда

- Блок тарифов удалён с главной страницы и показан справа от месячной формы в разделе «Аналитика» на широком экране.
- Для предыдущего и текущего месяцев одновременно видны правильные названия месяцев, тарифы без НДС, ставки НДС и рассчитанные суммы.
- Поля ручного ввода тарифа с НДС отсутствуют.
- Дробные тарифы с запятой и точкой принимаются, а отрицательные, пустые, неверные и чрезмерно длинные значения не сохраняются и сопровождаются подсказкой.
- Для нового месяца НДС равен `16`, при этом пользователь может сохранить другое корректное значение отдельно для каждого месяца.
- Суммы без НДС, НДС и с НДС правильно рассчитываются по месячному объёму и показываются до сотых: с двумя знаками после запятой, пробелами между тысячами и словом «тенге».
- Изменение объёма, тарифа или НДС сразу обновляет результаты без F5.
- При смене месяца и после F5 тариф и НДС каждого месяца остаются на месте, а ранее сохранённый тариф без НДС не теряется.
- На ширине 375px блок находится под месячной формой, все подписи, поля и результаты доступны, а интерактивные элементы не меньше 44px.
