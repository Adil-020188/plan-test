# Загрузка почасовых объёмов из Excel

## Для кого и зачем

Для субъекта оптового рынка электроэнергии, чтобы один раз загрузить фактические почасовые объёмы за предыдущий календарный месяц из файла Excel, а не переносить вручную данные каждого дня и часа.

## Что должно быть

- На странице есть блок «Загрузка предыдущего месяца» с полем выбора файла и кнопкой «Проверить файл».
- Принимается один локальный файл Excel в формате `.xlsx`. Старый формат `.xls` не принимается; пользователь видит подсказку «Сохраните файл в формате .xlsx».
- Страница читает файл только в браузере и ничего не отправляет в интернет.
- Данные берутся с первого листа книги.
- В первой строке таблицы должны быть три заголовка: `Дата`, `Час`, `Объём (кВт*ч)`. Порядок столбцов может быть любым, остальные столбцы не учитываются.
- Каждая следующая непустая строка содержит одну дату, один час и один объём:
  - дата — дата Excel или текст в формате `ДД.ММ.ГГГГ`;
  - час — целое число от `0` до `23` либо интервал от `00:00–01:00` до `23:00–00:00`;
  - объём — ноль или положительное число, в том числе дробное; разделителем дробной части может быть запятая или точка.
- Все строки файла должны относиться к одному календарному месяцу. Этот месяц должен непосредственно предшествовать месяцу правой даты «Текущий месяц» на странице.
- До загрузки страница проверяет файл целиком и показывает:
  - название файла;
  - найденный месяц;
  - количество корректных строк;
  - количество разных дат;
  - общую сумму объёмов в кВт*ч;
  - список ошибок с номером строки Excel и короткой причиной.
- Для каждой даты допускается не больше одной строки на каждый час. Повтор пары «дата + час» считается ошибкой.
- Пустая дата, неверный час, пустой, отрицательный или неверный объём считаются ошибками. Значения `NaN` и `Infinity` не показываются и не сохраняются.
- Если найдена хотя бы одна ошибка, кнопка «Загрузить объёмы» недоступна и никакие данные из файла не сохраняются.
- Если ошибок нет, доступна кнопка «Загрузить объёмы».
- После нажатия «Загрузить объёмы» каждая строка записывается в `localStorage` по своей дате и часу как объём предыдущего месяца.
- Импортируемое значение заменяет ранее сохранённый объём только для той же пары «дата + час». Объёмы других дат и часов, объёмы текущего месяца и тарифы не изменяются.
- После успешной загрузки показано сообщение: «Загружено: N строк за ММ.ГГГГ».
- Если слева выбрана дата из загруженного месяца, её 24 почасовых поля сразу обновляются. Для другой даты загруженные значения появляются после её выбора.
- После F5 импортированные объёмы остаются на месте.

## Примеры

- В файле есть строки `15.10.2026 | 0 | 100,5` и `15.10.2026 | 1 | 120`. Справа выбрана дата ноября 2026 года. После загрузки для даты `15.10.2026` в часах `00:00–01:00` и `01:00–02:00` показаны `100,5` и `120` кВт*ч.
- В файле час записан как `23:00–00:00` → объём попадает в строку `23:00–00:00`, а не в следующий день.
- В строках 8 и 9 повторяются дата `15.10.2026` и час `5` → показана ошибка о повторе, файл не загружается.
- В строке 12 объём равен `-10` → показано «Строка 12: объём не может быть отрицательным», файл не загружается.
- Файл содержит даты октября и ноября 2026 года → показано «В файле должны быть данные одного месяца», файл не загружается.
- Справа выбрана дата декабря 2026 года, а файл содержит октябрь 2026 года → показано «Загрузите данные за ноябрь 2026 года», файл не загружается.
- До импорта для `15.10.2026`, часа `00:00–01:00`, сохранено `90`. В корректном файле указано `100,5` → после загрузки показано `100,5`; остальные часы этой даты не меняются.

## Ограничения

- Только HTML, CSS и JavaScript без npm, библиотек и внешних ресурсов.
- Поддерживается только `.xlsx`; файлы `.xls`, `.xlsm`, `.ods` и `.csv` не загружаются.
- Обрабатывается только первый лист книги.
- Формулы допустимы только тогда, когда в файле сохранено готовое вычисленное значение. Страница не вычисляет формулы Excel.
- Размер файла — не более 5 МБ. Для большего файла показана подсказка «Файл больше 5 МБ».
- Максимум — 744 строки данных: 31 день × 24 часа.
- Полный набор из 24 часов для каждой даты не обязателен: отсутствующие в файле часы не изменяются.
- Перед записью проверяется весь файл. Частичная загрузка корректных строк при наличии ошибок запрещена.
- Интерфейс полностью на русском языке. Поле выбора файла и кнопки имеют высоту не меньше 44px и доступны на экране шириной 375px.
- Объёмы хранятся в кВт*ч. Тарифы без НДС и с НДС эта функция не импортирует и не изменяет.

## Готово, когда

- Корректный `.xlsx` за предыдущий месяц проходит проверку, показывает верные месяц, число строк, число дат и общую сумму.
- После подтверждения все строки попадают в правильные даты и часы, включая час `23:00–00:00`.
- Ошибочный файл не изменяет ни одного ранее сохранённого значения.
- Повторы дат и часов, неверные даты, часы, объёмы, другой месяц, неподдерживаемый формат и превышение размера получают понятные сообщения.
- Повторный импорт заменяет только совпавшие даты и часы и не меняет остальные объёмы и тарифы.
- После F5 импортированные данные сохраняются.
- Загрузка и сообщения доступны на телефоне шириной 375px.
